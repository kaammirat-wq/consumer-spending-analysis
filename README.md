# Consumer Spending Analysis (2022–2024)

## Project Overview
This project analyzes average annual consumer expenditures across income groups in the United States from 2022 to 2024. Using R, I explored differences in spending by income level and examined how spending changed over time.

## Data Source
U.S. Bureau of Labor Statistics (BLS) — Consumer Expenditure Surveys

https://www.bls.gov/cex/tables.htm

## Tools and Skills
- R and RStudio
- Data cleaning and preparation
- Data filtering and grouping using `dplyr`
- Data visualization using `ggplot2`
- Trend analysis and interpretation

## Key Findings
- Average annual spending increased across all five income quintiles from 2022 to 2024.
- Higher-income groups consistently spent more than lower-income groups.
- In 2024, the highest-income quintile spent approximately $150,342 annually, compared with $35,046 for the lowest-income quintile.
- Increases in nominal spending do not necessarily indicate increases in purchasing power.
